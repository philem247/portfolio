# Philip Adeoye — Portfolio Website

Personal portfolio website for **Philip Adeoye**, Full-Stack Web & Automation Developer.

Showcasing production web applications, Paystack payment workflows, and WhatsApp/Telegram bot automation.

## 🚀 Featured Projects
- **Teda Foods**: Campus food-ordering platform with Paystack & WhatsApp checkout. ([Live](https://teda-foods.vercel.app))
- **GoalNotif & Community Bots**: High-uptime WhatsApp automation engine built with Node.js & Baileys.
- **Focus Flow**: Deep-work ambient productivity companion with Web Audio API. ([Live](https://focus-flowff.vercel.app))
- **SpellForge**: Voice-synthesized vocabulary engine with Supabase persistence. ([Live](https://spell-forgee.vercel.app))

## 🛠️ Tech Stack
- **Design & Layout**: Semantic HTML5, CSS3, Inter & JetBrains Mono typography, custom glassmorphism & responsive cards.
- **Frontend Core**: Vanilla CSS/JS (Zero dependency, instant 100/100 Lighthouse performance).
- **Hosting**: Vercel.

## 📦 How to Deploy to Vercel

### Option 1: Via Vercel CLI (Fastest)
From this directory:
```bash
npx vercel
```
Follow the prompts to link and deploy in 10 seconds.

### Option 2: Via GitHub
1. Create a new GitHub repo: `philem247/portfolio`
2. Push this directory:
```bash
git init
git add .
git commit -m "feat: initial modern portfolio release"
git branch -M main
git remote add origin https://github.com/philem247/portfolio.git
git push -u origin main
```
3. Import the repo into your [Vercel Dashboard](https://vercel.com).
